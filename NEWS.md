# nanoflow 0.1.0

First release: end-to-end Oxford Nanopore WGS orchestration.

## Pipeline (Phase 1, default tool per step)

* `run_pipeline()`: sample-sheet driven, per-sample processing with
  resume (existing outputs are skipped) and a JSON provenance log.
* Basecalling: `basecall_dorado()` (GPU; skipped with a clear message when
  no GPU is present), `basecall_guppy()` (deprecated, kept for parity with
  the design diagram).
* QC/trimming: `qc_nanoplot()`, `qc_pycoqc()`, `qc_fastqc()`,
  `trim_porechop()`, `filter_filtlong()`, `qc_multiqc()`.
* Alignment: `align_minimap2()` (Nanopore), `align_bwa()` (Illumina),
  `bam_qc_qualimap()`.
* Assembly (optional branch): `assemble_flye()`, `polish_racon()`,
  `polish_medaka()`, `asm_qc_quast()`.
* Variants: `call_clair3()` (small), `call_sniffles()` (SV).
* Phasing: `phase_whatshap()` (phased VCF, haplotagged BAM, stats, switch
  errors vs truth).
* Annotation: `annotate_snpeff()` (+ `build_snpeff_db()` for custom
  genomes), `annotate_annotsv()`.
* Benchmarking (automatic when the sample sheet has truth VCFs):
  `benchmark_happy()`, `benchmark_truvari()`.
* Reporting: `render_report()` (HTML across samples),
  `write_igv_session()`, `igv_snapshots()`.

## Phase 2 alternatives

* `assemble_canu()`, `assemble_wengan()` (hybrid with Illumina),
  `call_medaka()`, `call_svim()`, `call_nanovar()`, `merge_survivor()`,
  `cnv_spectre()`, `phase_hapcut2()`.

## Infrastructure

* All locations from a YAML config (`read_config()`,
  `write_config_template()`); per-tool binary overrides; no hard-coded
  paths/users/hostnames.
* `check_tools()` verifies every binary + version before a run.
* `download_references()` fetches GRCh38 and SnpEff/AnnotSV databases into
  a user-chosen directory.
* `submit_slurm()`: thin per-sample sbatch wrapper (`dry_run` supported).
* `inst/conda/environment.yml` (+ separate hap.py env) and
  `inst/container/nanoflow.def` (Apptainer) pin every external tool.
* Deterministic synthetic fixture (200 kb diploid genome, truth VCFs,
  ~30x Badread/ART reads) in `inst/extdata/sim`, generated by
  `data-raw/`; testthat suite runs CPU-only and skips cleanly per missing
  tool.

## Known notes

* Sniffles >= 2.6 skips contigs < 1 Mb unless `--all-contigs` is passed
  (exposed as `all_contigs =` / `extra_args`); the fixture config and
  tests set it.
* hap.py requires Python 2.7 and therefore its own conda environment.
